# Changelog

This file records notable user-facing and maintainer-facing changes. The project has not declared every historical commit as a release; entries remain under **Unreleased** until a reviewed tag is created.

## Unreleased

### Added

- Reusable, dependency-free OSS readiness GitHub Action.
- Deterministic repository-artifact audit with Markdown and JSON output.
- Tests for complete, blocked, and malformed-package scenarios.
- Public contribution, governance, conduct, issue, and pull-request workflows.

### Notes

The readiness score measures repository artifacts only. It does not measure adoption, ecosystem importance, maintainer responsiveness, or eligibility for an external program.
