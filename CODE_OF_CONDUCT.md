# Code of conduct

Luna Swarm contributors and maintainers are expected to keep project spaces technically rigorous, respectful, and safe for participation.

## Expected behavior

- Discuss ideas and evidence rather than attacking people.
- Give specific, actionable feedback and acknowledge uncertainty.
- Respect different experience levels, languages, and communication styles.
- Protect private information, credentials, vulnerability details, and unpublished reports.
- Stop disruptive behavior when a maintainer asks.

## Unacceptable behavior

Harassment, threats, discriminatory abuse, sexualized attention, doxxing, impersonation, deliberate misinformation, spam, and repeated bad-faith disruption are not accepted. Publishing another person's private information or sensitive security report without permission is prohibited.

## Scope

This code applies in repository issues, pull requests, discussions, reviews, project chat, release coordination, and public interactions where someone is representing the project.

## Reporting

Do not post sensitive details publicly. Contact the lead maintainer through a private channel shown on their GitHub profile or through the repository's private security-reporting facility when available. When no private channel is available, open a minimal issue requesting private contact without including the sensitive content.

## Enforcement

The lead maintainer may edit or remove content, request a correction, issue a warning, temporarily restrict participation, or permanently ban an account. Decisions consider severity, intent, impact, recurrence, and willingness to repair harm. Retaliation against a reporter is prohibited.

The maintainer should preserve confidentiality as far as reasonably possible and document public outcomes without exposing a reporter or affected person.
