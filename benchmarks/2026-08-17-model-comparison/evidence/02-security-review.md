# 보안 및 개인정보 검토

검토일: 2026-07-03

## 발견 사항

1. **Critical — 교차 테넌트 캐시 키 결함**
   - 응답 캐시 키에 `tenant_id`가 포함되지 않는다.
   - 합성 재현 50회 중 2회에서 다른 테넌트의 요약 문장이 반환됐다.
   - 전면 출시 전 캐시 무효화, 키 스키마 변경, 회귀 테스트가 필요하다.

2. **High — 프롬프트 인젝션에 의한 내부 메모 노출**
   - 공격 시나리오 100건 중 3건에서 상담원 전용 내부 메모 일부가 답변 초안에 포함됐다.
   - 외부 콘텐츠 격리와 출력 DLP가 필요하다.

3. **High — 데이터 보존기간 불일치**
   - 실제 원문 로그 보존은 90일이다.
   - 승인된 개인정보 영향평가의 상한은 30일이다.

4. **Medium — 감사 로그 불완전**
   - 비동기 flush 실패로 파일럿 호출의 17%에서 prompt hash가 누락됐다.
   - 누락된 호출은 사후 재현이 불가능하다.

현재 보안 결론은 `전면 출시 차단`이다. 수정 후 독립 재시험이 필요하다.
